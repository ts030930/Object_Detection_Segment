# 에지 검출의 고전적인 기법

고전적인 컴퓨터비전에서의 에지 검출은 사람의 의미분할과 달리
단지 화소값에만 의존 가능하기 떄문에 의미론적인 분할은 불가능하다.
의미 분할은 딥러닝으로 가능하지만, 계산량이 적어야하는 임베디드 시스템에서 이용가능하다.

# 영상의 미분과 Sobel FIlter

미분은 변수 x의 값이 미세하게 증가했을 때 함수의 변화량이고,
영상에 미분을 적용한다면 픽셀에 따라 변화하는 화소값을 의미할 것이다.
이러한 변화를 찾기 위해서 미분을 이용하는것이다.

## Canny 

Canny는 딥러닝이 나온 지금 시점에서도 가장 체계적인 에지 검출이론이라고 평가 받는다.
최소 오류율, 위치 정확도, 두께라는 기준으로 목적함수를 정의하고 에지 검출을 최적화 문제로 해결했다.

이때 두께를 판단하기 위해 NMS를 이용하는데, 에지 방향에 수직인 두 이웃의 화소의 에지 강도가 자신보다 작으면 에지로 남고 아니면 에지가 아닌것으로 변화 시킨다.
즉 이웃 두 화소와 비교해서 자신이 제일 크지 않으면 제거되는 것이다.
